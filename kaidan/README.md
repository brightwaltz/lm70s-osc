# 怪談サイコロ（録音版）

APC40 mkII の 8×5 パッドで、用意した怪談の録音を話ごと・段階ごとに切り替えて流し、LM70S の照明で演出する。音は語りに、合成した環境音・心音・「ドン」を重ねる。すべてこの Mac で動く（PC-A・PC-B は使わない）。

```
APC40 mkII ─USB─▶ tools/apc_proxy.py ─▶ Live（ノブ → LM70S。今までどおり）
                        │ SHIFT + MASTER でパッド・フェーダーを怪談サイコロへ
                        ▼
                  kaidan/kaidan_dice.py ─ 音 ─▶ Mac のスピーカー
                        └─ 照明キュー OSC ─▶ 127.0.0.1:9000（osc_relay.py）─▶ LM70S
```

## 録音について

- 録音はご本人の語り（YouTube から録ったもの）とみられる。手元で試すのはよいが、人前で流すなら権利を確認すること。
- 録音・文字起こし・切り出した音声・`stories.json` は公開リポジトリに入れない（`kaidan/.gitignore`）。
- 実在の災害を扱う 2 話（震災・航空機事故）は、意図的に `stories.json` に入れていない。4 本目の最後の広告も使っていない。

## 1 回だけやること

文字起こし（済み）: whisper.cpp（`brew install whisper-cpp`）と `models/ggml-large-v3-turbo.bin`。結果は `transcripts/`。

録音を話ごとに切り出す（`stories.json` を変えたらやり直す）:

```bash
cd ~/dev/lm70s-osc && .venv/bin/python kaidan/build_audio.py
```

## 起動

ターミナルを 3 つ使う。

1. 照明の中継を `--changes-only` 付きで起動し直す（Live が 1 秒ごとに送り直す値で、怪談の照明を上書きしないため）

```bash
cd ~/dev/lm70s-osc && .venv/bin/python tools/osc_relay.py --target 192.168.128.135:9004 --changes-only
```

2. APC40 の中継役を起動し、Live の **Settings › Link, Tempo & MIDI** で Control Surface 1（APC40 mkII）の Input/Output を `APC40 proxy` に変える。実物の `APC40 mkII` の Track と Remote はオフにする（README「11.」）

```bash
cd ~/dev/lm70s-osc && .venv/bin/python tools/apc_proxy.py
```

3. 怪談サイコロを起動して、APC40 で **SHIFT + MASTER** を押す（MASTER が点灯したら怪談サイコロ側）

```bash
cd ~/dev/lm70s-osc && .venv/bin/python kaidan/kaidan_dice.py
```

レーザーも使うときは、もう 1 つのターミナルで LaserCube Local も起動する（下の「LaserCube」。起動の順番はどちらが先でもよい）。

Live を使わないときは `--apc direct`（APC40 を直接つかむ。Live の Control Surface から外しておく）。APC40 なしで試すときは `--simulate`（キーボードで操作）。ライトに送らずに試すときは `--no-lights`。

## APC40 の割り当て

| 操作 | 内容 |
|---|---|
| パッド 8×5 | 列 = 話、行 = 段階（上から 導入・情景・積み上げ・怪異・結末）。押すとその場所へすぐ切り替わる。色は照明ムード、いまの段階が点滅 |
| SCENE LAUNCH 1 | 話のサイコロを振る（列が回って止まり、その話を最初から） |
| SCENE LAUNCH 2 | 語りの一時停止 / 再開（止まっているときは振る） |
| SCENE LAUNCH 3 / 5 | 次の段階 / 前の段階 |
| SCENE LAUNCH 4 | ドン！（ストロボ → 1 秒暗転 + 低い衝撃音） |
| TRACK SELECT 1-6 | 照明ムード: 月光・蝋燭・非常灯・稲光・闇・霧 |
| TRACK SELECT 7 / 8 | ムードのサイコロを振る / 話ごとのムードに戻す（8 が点灯 = 話に合わせている） |
| CLIP STOP | その列の話を止める |
| STOP ALL CLIPS | ブラックアウト（語りは続く） |
| トラックフェーダー 1-6 | 語り・環境音・心音・照明の明るさ・ゆらぎの強さ・驚かしの強さ |
| マスターフェーダー | LM70S 全体の明るさ（`/lm70s/master`） |
| SOLO 1 | ワンタップデモ（約 85 秒。点滅中はデモ中。もう一度押すと止まる） |
| SOLO 2 | レーザーの開始 / 停止（点灯 = 出力中） |
| SOLO 3-6 | レーザーの図形: 円・8の字・三角・赤い手形（点灯 = いまの図形） |
| SOLO 7 | レーザーを怪談に連動（点灯 = ON） |
| SOLO 8 | レーザーの色を次へ（赤→橙→黄→緑→水色→青→紫→白） |
| トラックフェーダー 7 / 8 | レーザーの明るさ（0〜5%）/ 大きさ（5〜30%） |
| クロスフェーダー | レーザーの「わらわら度」（手の数 1〜8） |
| ノブ | Live のまま（LM70S を手で操作） |

- 段階に合わせて照明が変わる: 導入 = 明るめ、情景 = やや暗く、積み上げ・怪異 = 暗く、結末 = ごく暗く。心音は段階が進むほど速くなる
- 怪異の場面（`stories.json` の `scares`）に来ると、自動でストロボと「ドン」が入る。パッドで飛び越したときは鳴らない
- 環境音（うなり・風）、心音、「ドン」は起動時にメモリ上で合成し、語りと一緒にその場で混ぜて鳴らす（ファイルには書き出さない）

## ワンタップデモ（SOLO 1）

「押入れの向こう」を使って、全部の機能を順に見せる。途中でパッドなどを押すと、デモの台本だけ止まって手動操作に移る（話はそのまま続き、フェーダーの値は元に戻る）。

| 秒 | 内容 |
|---|---|
| 0 | 話のサイコロ（列が回って止まる）→ 導入 |
| 12 / 16 | 情景へ切り替え / ムードのサイコロ → 蝋燭のゆらぎ |
| 24 | 積み上げ。環境音・心音・ゆらぎを 8 秒かけて強める |
| 34 | 怪異の手前へ → 自動でストロボ + ドン |
| 45 / 50 | 稲光のムード / 手動の「ドン！」 |
| 54〜57 | ブラックアウト |
| 58 | 結末。ムードを話に戻し、環境音・心音を弱める |
| 70〜72.5 | 一時停止 → 再開 |
| 80〜83.5 | 語りをフェードアウトして終了（フェーダーとムードを元に戻す） |

APC40 なしでデモだけ流すときは `--demo`（`--simulate` 中は `demo` と打つ）。音だけの書き出しは `out/demo.wav`。

## LaserCube（lasercube-local）

[lasercube-local](https://github.com/ideos2040kyui/lasercube-local) の OSC 入力を使って、APC40 からレーザーを操作する。この Mac では `~/dev/lasercube-local` に取得済み。

1. LaserCube Local を起動する。Chrome で http://localhost:8765 が開く

```bash
cd ~/dev/lasercube-local && python3 app.py --open
```

2. **その画面は開いたままにする。** 画面からの通信が 3 秒途切れると、lasercube-local がレーザーを止める（安全のための仕組み）
3. 画面の「MIDIを接続」は押さない。APC40 は怪談サイコロが受け持つので、押すと同じ操作が二重に届く
4. 怪談サイコロを起動すると、lasercube-local の OSC 受信を 127.0.0.1:**9002** で自動的に有効にする（9000 は照明の中継が使う）
5. 実機に出すときは、lasercube-local の画面で「LaserCube実機」を選び、確認欄にチェックして「実機への出力操作を許可」を押す。そのあと SOLO 2 で開始する（許可していないと開始は断られる）

連動（SOLO 7）を ON にすると、照明ムードに合わせてレーザーの色が、段階の緊張に合わせて動く速さが変わる。怪異の場面では 3 秒間「赤い手形 × 8」になり、元に戻る。**連動はレーザーを点けも消しもしない**（開始と停止は SOLO 2 だけ）。明るさの上限（5%）などの制限と、本体の緊急停止の確認は lasercube-local の README のとおり。

レーザーを使わないときは `--no-laser`。lasercube-local が起動していなくても怪談サイコロは動く（SOLO 2 を押すと「起動していません」と表示）。

## 話の並びを変える

`stories.json` の `grid`（1-8 が列、`null` は予備）を書き換えて `build_audio.py` をやり直す。予備に「親友の写真」「隣の別荘」がある。時刻は文字起こしから取った秒で、`build_audio.py` が近くの無音に合わせる。

## サウンドノベル「二人弟切・脈」（デモ用）

スライド「AI-Driven Bio-Soundnovel」のデモに合わせたモード。テラーが APC40 のパッドで「戸隠の廃校（分教場）」を文節ごとに語り、サバイバーは心拍を乱さないように耐える。心拍が乱れるとドキドキ・メーターが減り、尽きればテラーの勝ち。最後の「起こるようですね」まで残ればサバイバーの勝ち。切り貼りミスのパッドを押すと、ホラーがコメディになってメーターが回復する。

```
APC40 mkII ─▶ apc_proxy.py ─▶ kaidan/soundnovel.py ─ 語り・環境音・心音 ─▶ スピーカー
                                     ├─ 照明 OSC ─▶ 127.0.0.1:9000（osc_relay.py）─▶ LM70S
心拍センサー ─ OSC /bio/hr ─▶ UDP 9006 ─┤
                                     └─ メーター画面 ─▶ http://<この Mac>:8790/（観客用のモニター）
```

### 1 回だけやること

パッドの音声を切り出す（`novel.json` を変えたらやり直す）。台本（タイムスタンプ付き）の時刻は録音 01 と話す速さが違うので、台本の文字を whisper の文字起こしと照合して、録音上の位置に直してから無音で切る。

```bash
cd ~/dev/lm70s-osc && .venv/bin/python kaidan/novel_build.py --verify
```

`--verify` は切り出した全パッドを whisper で聞き直して、台本の文と比べる（30 秒ほど）。一致が 60% 未満のパッドに「要確認」が付く。切り出し位置がずれていたら、`novel.json` のそのパッドに `"trim": [頭, 尻]`（秒）を足してやり直す。

### 起動

怪談サイコロと同じ手順で、3 つ目のターミナルだけ `soundnovel.py` にする。APC40 で **SHIFT + MASTER**。

```bash
cd ~/dev/lm70s-osc && .venv/bin/python kaidan/soundnovel.py
```

観客用のモニターで `http://<この Mac の IP>:8790/` を開く（同じネットワークなら別の PC やタブレットでもよい）。末尾に `?notext` を付けると字幕を隠す。

APC40 なしで試すときは `--simulate`、全部自動で流すときは `--demo`（約 3 分）。

### 心拍の入れ方

- 心拍センサー側から、OSC で `/bio/hr <bpm>`（float か int）を UDP **9006** に、毎秒 1 回以上送る。先方のバイタルセンシングでも、手元のセンサーでもよい
- 3 秒途切れると、物語に反応する「仮のサバイバー」の心拍に切り替わる。センサーなしでもデモは成立する（メーター画面に「シミュレーション」と出る）。仮のサバイバーを使わないときは `--no-sim-survivor`
- 別のシステムがメーターを計算するなら、`/bio/meter <0-1>` で直接上書きできる
- `--events HOST:PORT` を付けると、`/novel/pad`・`/novel/scare`・`/novel/comedy`・`/novel/meter`・`/novel/phase` をそこへ送る（先方のシステムで物語の進行を使う場合）

### ルール（`meter.py`）

| 場面 | メーター |
|---|---|
| 開始から 8 秒 | 平常心（心拍の基準）を測る。最初のパッド（穏やか）がちょうどこの間に流れる |
| 心拍が平常心 + 5 bpm を超えている間 | 超えた分に比例して減る（20 bpm 超えで毎秒約 1.4%） |
| 2 秒以内に 12 bpm 以上跳ね上がる | 5% 減る（驚いた瞬間） |
| 切り貼りミスのコメディ（4 秒間） | 毎秒 2.5% 回復する |
| 0% になる | テラーの勝利。照明は赤、語りは止まる |
| 「起こるようですね」が最後まで流れる | サバイバーの勝利。照明は緑 |

仮のサバイバーは、驚かしの間を空けるほど、また落ち着いた場面の直後ほど大きく反応する（スライドの「緩急」）。同じ 4 回の驚かしでも、2 秒おきだとメーターは 29%、20 秒おきだと 44% 減る。ワンタップデモ（SOLO 1）は、間を取りながら本筋を流し、途中で 1 回わざと押し間違える。最後の「誰もいなかった」（約 2 分 55 秒）でメーターが尽きて、テラーが勝つ。

### APC40 の割り当て

| 操作 | 内容 |
|---|---|
| パッド 上 3 段 | 本筋 20 パッド。列ごとに上から下へ読む（列 1 導入 → 列 2 恐怖① → 列 3 車 → 列 4 恐怖② → 列 5 タクシー → 列 6 恐怖③ → 列 7 結末）。押すとその文節が流れて止まる。次を押すまでの「間」もテラーの腕の見せ所 |
| パッド 下 2 段 | 切り貼りミス 9 パッド（黄色）。そのすぐ上の文節の次に押すと話がチグハグになる。流れ終わるとコメディ演出（色が回る照明 + ボヨン）が入り、メーターが回復する |
| パッドの色 | 穏やか = 橙、不穏 = 青、恐怖 = 紫、襲撃 = 赤、結末 = 白、切り貼りミス = 黄。流れているパッドは点滅、流し終わったパッドは暗くなる |
| SCENE LAUNCH 1 | ゲーム開始 / やり直し（メーターを 100% に戻し、平常心を測り直す）。パッドを押しても始まる |
| SCENE LAUNCH 2 | 語りの一時停止 / 再開 |
| SCENE LAUNCH 3 | 本筋の次のパッド |
| SCENE LAUNCH 4 | ドン！（ストロボ → 暗転 + 衝撃音） |
| SCENE LAUNCH 5 | 語りを止める（間を作る） |
| CLIP STOP 1-8 | ドキドキ・メーター（点灯している数 = 残り。減りかけの 1 つが点滅） |
| TRACK SELECT 1-6 / 8 | 照明ムード / パッドに合わせる |
| STOP ALL CLIPS | ブラックアウト |
| トラックフェーダー 1-6、マスターフェーダー | 怪談サイコロと同じ（語り・環境音・心音・照明の明るさ・ゆらぎ・驚かしの強さ、LM70S の明るさ）。心音はサバイバーの心拍の速さで鳴る |
| SOLO 1 | ワンタップデモ |
| SOLO 2-8、フェーダー 7-8、クロスフェーダー | レーザー（怪談サイコロと同じ） |

パッドの種類ごとの照明: 穏やか = 蝋燭・明るめ、不穏 = 月光・やや暗く、恐怖 = 闇・暗く、襲撃 = 赤い非常灯・暗く（山場で自動のストロボ + ドン）、結末 = 月光・ごく暗く。「ギィーッ」の音に合わせて照明が一瞬沈む。

### スライドのデモの流れとの対応

| スライド | このモードでは |
|---|---|
| STEP 1 準備（AI が音声を分割・タグ付け、パッドにセット） | `novel_build.py`。台本と録音を照合して 29 パッドに切り分け、穏やか / 不穏 / 恐怖 / 襲撃 / 結末 / 切り貼りミスのタグと、驚かし・きしみの位置を付ける |
| STEP 2 プレイ開始（穏やかなシーン、反応を伺う） | 開始から 8 秒で平常心を測る。導入の 3 パッドは穏やか |
| STEP 3 襲撃（メーター急降下、秘訣は緩急） | 襲撃パッドの山場で自動のストロボ + ドン。間を空けた驚かしほど効く |
| 注意（押し間違えるとコメディに） | 下 2 段の切り貼りミス（切り貼り案01 とトンチンカン編から 9 個）。メーターが回復するのでテラーには損 |
