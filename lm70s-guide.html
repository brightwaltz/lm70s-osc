LM70S×APC40 mkII×Ableton Live

APC40 mkII のノブと Live のクリップで LM70S を動かすためのガイドです。Live 12 Lite のまま使えるように、Live の中のリモートスクリプトが OSC を送り、Python のブリッジが DMX に変換します。Live を使わずに APC40 から直接 OSC を送るモードと、DMX をサーバーから出す構成もあります。

LM70S 本体
14CH モード · アドレス 001
OSC の宛先
127.0.0.1:9000
追加で必要なもの
USB-DMX インターフェース
プロジェクト
~/dev/lm70s-osc
ブリッジとスクリプトの動作はテストで確認済み。実際の Live と LM70S ではまだ動かしていません。
Signal flow

信号の流れ

使い方は 3 通りあります。構成を切り替えて、各ブロックを選ぶと役割と設定が表示されます。

    Setup

    セットアップ

    上から順に進めます。チェックはこのブラウザに保存されます。

    0 / 6 完了
    1. 1

      LM70S 本体を設定する

      本体パネル（MODE/ESC・UP・DOWN・ENTER）で、チャンネルモードを 14CH、DMX アドレスを 001、動作モードを DMX にします。9CH でも動きますが、Pan/Tilt が 8bit になり動きが粗くなります。

      USB-DMX インターフェース → DMX ケーブル（XLR 3pin）→ LM70S の DMX IN の順につなぎます。チェーンの最後にターミネーターを付けると信号が安定します。

    2. 2

      ブリッジを準備する この Mac では済み

      cd ~/dev/lm70s-osc && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
    3. 3

      リモートスクリプトを入れる この Mac では済み

      cd ~/dev/lm70s-osc && ./install_remote_script.sh

      ~/Music/Ableton/User Library/Remote Scripts/LM70S_OSC にコピーされます。config.py を変えたら再実行してください。

    4. 4

      Live を設定する

      1. Live を再起動し、Settings › Link, Tempo & MIDI を開く
      2. Control Surface 1: APC40 mkII（Input/Output も APC40 mkII）
      3. Control Surface 2: LM70S_OSC（Input/Output は None）
      4. MIDI トラックを 1 本作り、名前を LM70S にする
      5. Instruments から空の Instrument Rack をそのトラックにドロップ
      6. Macro 9〜12 も使うなら、Rack の「+」で Macro を 16 個まで表示する

      ステータスバーに LM70S_OSC: track 'LM70S': ... -> 127.0.0.1:9000 と出れば成功です。MIDI Effect Rack ではなく Instrument Rack を使うのは、トラックにボリュームフェーダーを持たせて全体の明るさに使うためです。

    5. 5

      ブリッジを起動する

      お使いの USB-DMX インターフェースの種類を選ぶと、コマンドが切り替わります。

      
          
      Live を使わずに照明だけ確かめるときは、別のターミナルでデモを流します（20 秒間、円を描きながら色が変わります）。
      
          
      cd ~/dev/lm70s-osc && .venv/bin/python tools/osc_send.py demo
      
          
      Ctrl+C で止めると、ヘッドを動かさずに消灯してから終了します。

      APC40 で動かす
      
          
      Live でトラック LM70S を選ぶと、DEVICE CONTROL の 8 つのノブが Rack の Macro に割り当たります。DEV. LOCK を押しておくと、他のトラックを選んでもノブは照明を操作したままです。LM70S トラックのフェーダーが全体の明るさです。

      Clips
      
      クリップで照明を演出する
      
      
      Macro はクリップのエンベロープで自動化できます。照明の動きをクリップにしておけば、APC40 のグリッドから曲に合わせて起動できます。
      
    
      
    
      
      
      
        
      照明クリップを作る
      
        
        
          
      1. LM70S トラックに空の MIDI クリップを作る
        2. 
          
      2. Clip View の Envelopes で Device = Instrument Rack、Control = Macro を選ぶ
        3. 
          
      3. Pan をサイン波で振る、Red から Blue に変える、などを描く
        4. 
        
      
      
      
      
      
        
      曲と同期させる
      
        
      クリップは Live の Launch Quantization（グローバル クオンタイズ）で小節頭にそろって切り替わります。音楽のクリップと照明クリップを同じシーン行に置けば、シーン起動ボタン一つで両方が切り替わります。
      
      
      
      
      
        
      Lite で気をつけること
      
        
      Live 12 Lite はトラックが 8 本までです。照明用に 1 本使うので、音楽に使えるのは 7 本になります。
      
      
      
    
      
  
      

  
      
    
      
      Without Ableton
      
      Ableton なしモード
      
      
      tools/apc2osc.py が APC40 mkII を直接読み、照明専用のコントローラーとして OSC を送ります。Live は使いません。Live が APC40 を使っていると LED と操作がぶつかるので、Live を終了するか、Control Surface から APC40 mkII を外してから起動します。
      
    
      
    
      
      
      
        
      起動する
      
        
      ターミナル 1：ブリッジ
      
        
      cd ~/dev/lm70s-osc && .venv/bin/python bridge/osc2dmx.py --output enttec-pro --monitor
      
        
      ターミナル 2：APC40
      
        
      cd ~/dev/lm70s-osc && .venv/bin/python tools/apc2osc.py
      
        
      起動直後は何も送りません（ブリッジの初期値は中央向き・消灯）。触ったパラメータから送られます。終了すると APC40 の LED を消します。
      
      
      
      
      
        
      操作の割り当て
      
        
      
          
      DEVICE CONTROL ノブ 1–8
      Pan · Tilt · Dimmer · Strobe · Red · Green · Blue · White（Ableton 経由と同じ並び。LED リングに値を表示）
      
          
      TRACK CONTROL ノブ 1–4（上段）
      Speed · Color · Color Speed · Program
      
          
      トラックフェーダー 1–8
      1〜8 台目の Dimmer
      
          
      マスターフェーダー
      全台の Master（明るさの掛け算）
      
          
      TRACK SELECT 1–8 / MASTER
      ノブとパッドの送り先を 1〜8 台目 / 全台（/all）に切り替え。選択中のボタンが点灯
      
          
      STOP ALL CLIPS
      ブラックアウトの ON/OFF。SHIFT と一緒に押すと選択中の台をリセット
      
        
      
      
      
    
      
    
      
      
      クリップグリッドのプリセット
      
      
      パッドを押すと、そのパッドが送る OSC を表示し、上の操作シミュレーターにも反映します。中身は tools/apc2osc_config.py の PRESET_ROWS で変えられます。
      
      
      
      
      パッドを押すと、送る内容がここに出ます。
      
    
      
  
      

  
      
    
      
      Remote DMX
      
      別マシンで DMX を出す
      
      
      ブリッジは Linux でも動きます。USB-DMX を Raspberry Pi などのサーバーにつなぎ、APC40（または Live）側の Mac から LAN 越しに OSC を送れます。サーバーの名前を入れると、下のコマンドが書き換わります。
      
    
      
    
      
      
      
        
        
      
      
    
      
    
        
      
      1. 1
        
        
        Mac からフォルダをコピーする
        
        
        
        
        .venv は除いてコピーします。
        
      
        2. 
      
      2. 2
        
        
        サーバーで準備する
        
        
        cd ~/lm70s-osc && python3 -m venv .venv && .venv/bin/pip install python-osc pyserial
        
        
        USB シリアルを一般ユーザーで開けるようにします（実行後、一度ログインし直す）。
        
        
        sudo usermod -aG dialout $USER
        
      
        3. 
      
      3. 3
        
        
        サーバーでブリッジを起動する
        
        
        cd ~/lm70s-osc && .venv/bin/python bridge/osc2dmx.py --output enttec-pro --monitor
        
        
        USB-DMX は /dev/ttyUSB* か /dev/ttyACM* として自動で見つかります。ファイアウォールで UDP 9000 を開けておいてください。
        
      
        4. 
      
      4. 4
        
        
        Mac 側の送り先をサーバーにする
        
        
        Ableton なしモードの場合
        
        
        
        
        
      
        5. 
    
      
    
      APC40 をサーバーに直接つなぎ、サーバー上で apc2osc.py を動かすこともできます（Mac 不要）。その場合はサーバーでも pip install -r requirements.txt を実行します。python-rtmidi のビルドに sudo apt install libasound2-dev が必要なことがあります。
      
  
      

  
      
    
      
      OSC reference
      
      OSC アドレス
      
      
      TouchOSC など他のアプリやスマホからも、ブリッジへ直接送れます。ブリッジは 0.0.0.0:9000 で待ち受けます。float は 0.0〜1.0 の割合、int は DMX の生値（0〜255）として扱います。
      
    
      
    
      
      
      
        
      アドレス内容
      
        
          
      /lm70s/<param>pan · tilt · dimmer · strobe · red · green · blue · white · speed · color · color_speed · program · master
      
          
      /lm70s/reset1 を送ると Reset チャンネルを 5 秒間保持（本体のリセット動作）
      
          
      /all/<param>全台に同じ値を送る
      
          
      /blackout1 で全消灯、0 で解除
      
          
      /dmx/<ch>1 チャンネルの値を直接上書き（動作確認用）
      
          
      /dmx/clear直接上書きをすべて解除

      Max for Live
      
      Max for Live があると何が増えるか
      
      
      Max for Live は Live 12 Suite に付属し、Standard にはアドオンとして追加できます。Lite と Intro では動きません。Cycling '74 の Max 単体を買っても、Lite の中では使えません。
      
    
      
    
      
      
      
        
      やりたいこと今の構成（Lite）Suite（Max for Live 込み）
      
        
          
      APC40 で手動操作できるできる
      
          
      クリップで照明を自動化、曲と同期できるできる
      
          
      テンポに合わせて Pan/Tilt を揺らすエンベロープを手で描くLFO デバイスを Macro にマップする
      
          
      音に反応させる（キックでストロボ等）難しいEnvelope Follower で音量を Macro に送る
      
          
      OSC の送信自作リモートスクリプトConnection Kit の OSC 送信デバイスでも可
      
          
      ブリッジなしで Live から直接 DMXできないBeam for Live（別売、LM70S のプロファイルあり）
      
          
      トラック数8 本まで無制限
      
              
      
      
    
      
    
      
      
      判断の目安
      
      
      APC40 で手動操作し、クリップで演出する分には、今の構成で足ります。音に反応する照明やテンポ同期の揺れを手軽に付けたい場合、ブリッジを使わず Live から直接 DMX を出したい場合は、Suite へのアップグレードで実現できます。
      
      
      定価は Standard が USD 349、Suite が USD 749 です（Ableton のアップグレードページの表示）。Lite からはアップグレード価格が出ることがあるので、Ableton のアカウントで確認してください。Beam for Live は別売で約 USD 199 です。LFO や Envelope Follower が今のリモートスクリプト経由で OSC に流れるかは、まだ確かめていません。
      
    
      
  
      

  
      
    
      
      Troubleshooting
      
      うまく動かないとき
      
    
      
    
      
      
      Live のステータスバーに何も出ない
      Live のログ ~/Library/Preferences/Ableton/Live 12.4.7/Log.txt で LM70S_OSC を検索してください。トラック名が LM70S になっているか、Control Surface 2 に LM70S_OSC が選ばれているかも確認します。
      
      
      ブリッジに OSC が届かない
      ブリッジに --verbose を付けて起動すると、受信した OSC をすべて表示します。何も出ない場合は、ポート番号（9000）が config.py と一致しているか確認してください。
      
      
      OSC は届くのに光らない
      Dimmer とフェーダーの両方が上がっているか確認します。Master は Dimmer × フェーダーで決まります。tools/osc_send.py /dmx/6 100i のように生値を送ると、本体が反応するか直接確かめられます。
      
      
      USB-DMX インターフェースが見つからない
      Mac は ls /dev/cu.*、Linux は ls /dev/ttyUSB* /dev/ttyACM* でデバイス名を調べ、--port /dev/cu.usbserial-XXXX のように指定します。FTDI 系のケーブルは open-dmx、ENTTEC Pro や DMXKing は enttec-pro を選びます。
      Linux で Permission denied と出る場合は、ユーザーが dialout グループに入っているか確認してください。
      
      
      Ableton なしモードで LED がおかしい、反応が二重になる
      Live が APC40 を Control Surface として使っていないか確認してください。Live を終了するか、Control Surface 1 を None にしてから apc2osc.py を起動します。
      
      
      Speed の向きが逆に感じる
      本体の仕様です。0 が最速の機種が多いので、Rack の Macro の範囲を反転して好みに合わせてください。
      
      
      Open DMX 系でちらつく
      マイコンを持たない USB-DMX は、PC 側で DMX のタイミングを作るため途切れやすくなります。ちらつく場合は Pro 互換のインターフェースを使うか、--fps 30 のように送信レートを下げてください。
